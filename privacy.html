Privacy policy

Moonlight smart display

Who uses this app

Moonlight is a personal smart display. Its Google sign-in is used only by the owner of this website, for the owner's own Google account and devices. It is not offered to the public.

What Google data it accesses

  • The list of Nest devices the owner chooses to share, and their state (for example, a thermostat's temperature).
  • Doorbell, person and motion events from those devices, including short event clips.
  • Live video from a camera, only while an alert is on screen.
  • Messages in the owner's own Google Cloud Pub/Sub subscription, which is how those events are delivered.

How the data is used

The data is used only to show alerts, video and readings on the owner's display at home. It is processed on the owner's own Raspberry Pi. Event clips are kept in memory for a few minutes and are not saved. No data is sold, shared with anyone else, used for advertising, or used to train AI models.

Moonlight's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The sign-in token and the app's settings are stored only on the owner's Raspberry Pi, in a file that only the Moonlight service can read. Nothing is stored on this website or on any other server.

Removing access

Access can be withdrawn at any time at nestservices.google.com/partnerconnections or in the Google Account's third-party access settings. Choosing Disconnect in Moonlight also deletes the stored token from the Raspberry Pi.

Contact

Questions about this policy can be sent to the owner of this website through its GitHub profile.
